# Git + GitHub + MkDocs博客项目结构与日常更新流程

(因为总是记不住,让AI总结了一篇教程)

这篇文章记录本博客项目的目录结构，以及以后**写文章、修改文章、上传 GitHub**的最简单操作流程。

目标很简单：

> **想写文章 → 放到正确目录 → 本地检查 → Git 提交 → Push → 等待网站自动更新。**

## 一、写一篇新文章

例如我要写一篇 LianoPo 服务器的文章。

先进入项目：

```bash
cd ~/homelab-blog
```

进入对应目录：

```bash
cd docs/servers/lianpo/
```

创建文章：

```bash
vim 新文章.md
```

例如：

```bash
vim IPv6配置记录.md
```

写完保存即可。

## 二、修改已有文章

直接编辑对应的 Markdown 文件：

```bash
vim docs/servers/lianpo/IPv6配置记录.md
```

或者使用自己喜欢的编辑器。

修改完成后，不需要做其他特殊操作。

## 三、写完后先看 Git 有没有发现修改

执行：

```bash
git status
```

例如：

```text
modified:   docs/servers/lianpo/IPv6配置记录.md
```

或者：

```text
new file:   docs/servers/lianpo/IPv6配置记录.md
```

说明 Git 已经发现修改。

## 四、上传博客的标准流程

以后最重要的就是记住下面这 **4 步**：

```bash
git pull --ff-only
git add .
git commit -m "提交说明"
git push
```

### 第 1 步：先同步 GitHub

```bash
git pull --ff-only
```

作用：

> **先把 GitHub 最新内容同步到本地。**

养成习惯：

**写博客之前先 pull。**

------

### 第 2 步：添加修改

```bash
git add .
```

作用：

> 把这次新增、修改、删除的文件交给 Git 准备提交。

这里的 `.` 表示：

> 当前项目目录下的所有修改。

------

### 第 3 步：创建 commit

```bash
git commit -m "新增LianoPo服务器记录"
```

其中：

```text
-m
```

表示后面的文字是**提交说明**。

例如：

```bash
git commit -m "新增LianoPo服务器记录"
git commit -m "修改网络配置文章"
git commit -m "增加服务器截图"
```

------

### 第 4 步：上传 GitHub

```bash
git push
```

看到类似：

```text
main -> main
```

一般就说明上传成功。

------

也就是：

> **Pull → Add → Commit → Push**

## 五、如果移动文章

推荐使用：

```bash
git mv 原位置 新位置
```

例如：

```bash
git mv docs/servers/luna/搭建mkdocs+github博客.md \
       docs/servers/lianpo/
```

然后正常：

```bash
git add .
git commit -m "调整博客目录"
git push
```

如果已经使用普通 Linux 命令：

```bash
mv 原位置 新位置
```

也没关系。

Git 会自动检测文件移动/重命名。

之后：

```bash
git status
git add .
git commit -m "调整博客目录"
git push
```

即可。

## 六、最重要的一张速查表

以后忘记的时候，只看这里：

```text
进入博客
    ↓
cd ~/homelab-blog
    ↓
先同步
git pull --ff-only
    ↓
写文章 / 修改文章 / 增删图片
    ↓
检查
git status
    ↓
加入修改
git add .
    ↓
提交
git commit -m "说明这次改了什么"
    ↓
上传
git push
    ↓
等待 GitHub 自动部署
    ↓
刷新博客网站
```

## 七、最常用的完整命令

```bash
cd ~/homelab-blog

git pull --ff-only

# 修改博客……

git status
git add .
git commit -m "本次修改内容"
git push
```

> **记不住 Git 也没关系。**
>
> 只要记住：
>
> **Pull → Add → Commit → Push**
>
> **先同步，再修改；修改之后 Add、Commit、Push。**
